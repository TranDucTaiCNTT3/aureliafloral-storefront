AURELIA FLORAL - GOI FILE BUILD TINH VA PRODUCTS.JSON

1. Giai nen goi nay vao thu muc goc project hien tai.
2. Ghi de file index.html hien tai bang index.html trong goi nay.
3. Giu nguyen package.json hien tai cua project admin. KHONG ghi de package.aurelia-build.json.
4. Mo package.aurelia-build.json, gop cac devDependencies: tailwindcss, sharp vao package.json hien tai.
5. Gop cac scripts: clean, build:css, optimize:images, copy:static va build vao scripts hien tai. Neu project da co script cung ten, uu tien gop logic thay vi ghi de mu.
6. Giu cac thu muc data/, src/ va scripts/ trong goi nay.
7. Chay npm install, sau do npm run build.

Luu y: images/ phai nam o thu muc goc project. Script se tao WebP/AVIF trong dist/images va cap nhat dist/data/products.json.
