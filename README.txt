Aurelia Floral — gói website tải xuống

Cấu trúc chính:
- index.html: trang bán hàng
- admin.html: trang quản trị
- images/: đặt ảnh sản phẩm JPG tại đây theo đúng tên được khai báo trong index.html
- assets/: ảnh OG và tài nguyên thương hiệu
- dist/: output static đã đồng bộ
- server.py: chạy preview bằng PORT=3000 python3 server.py

Lưu ý: project hiện chưa có 22 ảnh sản phẩm thật; images/ được tạo sẵn để bổ sung sau.
